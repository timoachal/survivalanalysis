This report presents a comprehensive survival analysis pipeline using simulated clinical datasets. We cover:

- **Kaplan-Meier (KM) survival curves** for visualising time-to-event data
- **Log-rank tests** to compare survival between groups
- **Cox Proportional Hazards models** for multivariable adjustment
- Analyses stratified by **treatment group, age, gender, SES, geography**, and **disease type**

All datasets are simulated to mirror realistic clinical scenarios.
